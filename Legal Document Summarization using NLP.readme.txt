1. Project Overview

This project implements an end-to-end NLP pipeline to automatically summarize long legal documents such as contracts, NDAs, and service agreements. The objective is to reduce manual review effort for legal professionals by generating concise summaries using AI.

Two approaches are implemented and compared:

Extractive Summarization (Lex-Rank)

Abstractive Summarization (BART Transformer)

2. Dataset

Dataset Name: Contract Understanding Atticus Dataset (CUAD)

Format: JSON

Usage: Raw legal contract text only

Dataset path:

data/raw/CUAD_v1.json

3. Methodology
3.1 Data Ingestion

Legal contracts are loaded from the CUAD dataset and parsed into plain text.

3.2 Preprocessing

Text cleaning and normalization

Token-based chunking to handle long documents

3.3 Summarization

Extractive: Lex-Rank algorithm (sentence selection)

Abstractive: BART (facebook/bart-large-cnn)

3.4 Evaluation

Evaluation is performed using:

ROUGE-1

ROUGE-2

ROUGE-L

Accuracy is not used as summarization is a generative task.

5. How to Run the Pipeline

From the project root directory, run:

python code/src/pipeline.py


This will:

Load contracts

Generate extractive summaries

Generate abstractive summaries

Compute ROUGE scores

Save results to outputs/

6. Generate PDF (Contract Summaries)

Run:

10. Conclusion

This project demonstrates a practical and scalable approach to legal document summarization using NLP. Extractive methods ensure legal accuracy, while abstractive methods improve readability. Together, they provide a strong foundation for AI-assisted legal review.
